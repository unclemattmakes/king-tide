# In-app track editor

The fast path for authoring + iterating a track. Owns gameplay data —
gates, AI spline, pickups, boost pads, start pose. Pair with Blender for
collidable environment geometry (see
[blender-pipeline-guide.md](./blender-pipeline-guide.md)).

## Open the editor

```
http://localhost:5191/?edit=1                       # opens lagoon-edit
http://localhost:5191/?track=<id>&edit=1            # opens a specific track
```

`<id>` can be:

- **`lagoon-edit`** (default) — JSON snapshot of the procedural Lagoon
  Loop. Generated by `node tools/snapshot_lagoon.mjs`; re-run that script
  if `lagoon-loop.ts` changes and you want to refresh the editable copy.
- An existing JSON track in `public/tracks/<id>.json` — opens for editing.
- A new id (e.g. `?track=mybeach&edit=1`) — opens an empty draft. Hit
  *Save* to write `public/tracks/mybeach.json`.

The two procedural tracks (`lagoon`, `cliffside`) are built in code and
not editable here.

## What's on screen

- **Water plane** — the world's flat reference at y=0.
- **Gates** as orange transparent goalposts (small forward-arrow shows
  gate orientation), indexed `cp_NN`.
- **Pickup spawns** as orange spheres.
- **Boost pads** as cyan slabs with a forward-arrow.
- **AI spline** as a polyline of blue dots; control points are draggable.
- **Outliner panel** (top-left): every entity grouped by kind, click to
  select.

## Workflow

1. **Select** an entity by clicking its row in the **Outliner**. The
   selected entity gets a Three.js TransformControls gizmo.
2. **Switch the gizmo mode** with the panel buttons or W / E / R hotkeys.
3. **Drag a gizmo handle** to move, rotate, or scale.
4. **Place new entities** with the **+ Gate / + Pickup / + Boost /
   + Spline pt** buttons — the next ground click drops the entity.
5. **Save** writes `public/tracks/<id>.json` via the dev middleware.
6. **Play** reloads without `?edit=1` so you immediately race the changes.

## Gizmo modes

| Mode | Hotkey | Affects |
|---|---|---|
| Move | `W` | Translate (X/Y/Z) |
| Rotate | `E` | Yaw around Y (gates + pads only) |
| Scale | `R` | Resize (gates: halfWidth + height; pads: halfWidth + halfDepth) |

- **Gates + Boost Pads** support all three modes.
- **Pickups + Spline points** are translate-only — rotate / scale are
  meaningless for a single point.
- The gizmo's restricted axes are reflected automatically (e.g. rotate
  on a gate only shows the Y ring; scale on a pad only shows X and Z).

When scaling, the helper visually stretches during the drag. On drag end
the gizmo's scale is **baked** into the entity's `halfWidth` / `halfDepth`
/ `height` fields and the helper is rebuilt at the new size with scale
reset to 1. Min sizes are clamped (0.5m) so a misclick can't zero an
entity.

## Camera

| Action | Effect |
|---|---|
| Left-drag | Orbit |
| Right-drag | Pan |
| Wheel | Zoom |

(OrbitControls — standard Three.js. Damped, polar-clamped to keep the
camera above the water plane.)

## Other controls

| Action | What it does |
|---|---|
| Click outliner row | Select that entity |
| Click `+ X` button | Arm placement; next ground click places |
| Esc | Cancel current place tool |
| Delete / Backspace | Remove selected entity (spline keeps ≥2 points) |
| Ctrl/Cmd + S | Save |

## Wiring the env .glb

Set `environmentGlb` in the JSON file to the public URL of your Blender
export. Example for `public/tracks/mybeach.json`:

```json
{
  "id": "mybeach",
  "environmentGlb": "/assets/tracks/mybeach.glb",
  ...
}
```

In editor mode the .glb is **not** loaded (you author against the bare
water plane without parallax distractions). It loads on Play.

## Limitations

- **No undo.** Save is the commit point; reload to abandon.
- **No diff vs. saved.** Status appears under the Save button; the
  underlying file isn't watched for outside changes.
- **Boost pads have no runtime effect yet.** They render and persist but
  the sim doesn't react. Wiring the speed-up is its own task.
- **Numeric input boxes are read-only.** The properties panel shows
  values but you can't type into them — use the gizmo. Hand-edit the
  JSON for fine-grained control.
